# Artica Interiors Design Engineering — Concept Demo

This is a **non-official concept website**, not affiliated with or endorsed by Artica Interiors Design Engineering.

## Files
- `index.html`: mobile-friendly static landing page and interactive concept browser
- `apartments.html`, `contact.html`, `coming-soon.html`: redirects preserving source template-style route names
- `assets/style.css`, `assets/app.js`: independent local styles and interaction logic
- `assets/concept*.svg`: original illustration assets; not photographs or actual business projects
- `data/client.json`: business listing data with explicit verification flags
- `outreach_pitch.txt`: draft cold email and SMS/WhatsApp copy (unsent)

## Deployment
Deploy the parent `customized_clients` directory as the static site root. Then this client is at `/client-09-artica-interiors-design-engineering/`. All internal files use `./` paths.

## Validation before use
1. Verify company name, location, phone, and website absence against a current official Google Business Profile.
2. Confirm WhatsApp registration if using it for outreach.
3. Replace illustrative images with *licensed, owner-approved* project photography (direct Google Maps photos may have attribution/licensing or hotlink limitations).
4. Publish first and replace the placeholder domain in `outreach_pitch.txt`.
5. Do not claim Google review ratings that have not been confirmed.
