# 20 UAE PropTech concept demos — Deployment

**Verification status:** All 20 are screening candidates. Absence of websites and Google Maps ratings/photos have not been independently verified. The contact numbers were directory-listed and need confirmation. The previews are independent concepts, not official business sites.

## Vercel (static, free tier if eligible)
Deploy the **contents of `customized_clients/` as the project root**. With a repository, set Root Directory to `customized_clients` and Framework Preset = Other / static, leaving build command empty. If Vercel requires an output directory, use `.`. A chosen Vercel project domain yields `https://YOUR-VERCEL-PROJECT.vercel.app/client-01-.../`. Do not send the outreach messages until previews actually resolve.

## Netlify Drop
Drag the `customized_clients/` directory into Netlify Drop. Netlify will serve the client folders at `/<slug>/`.

## GitHub Pages
Publish the **contents** of this directory from your configured root or `/docs` folder. The relative internal paths use `./` and function under each `<slug>/`.

## Before public launch
- Replace original illustrative SVGs with approved/licensed project photos. Do not reuse Google Maps photo URLs blindly.
- Verify business owners, addresses, ratings, telephone numbers, WhatsApp numbers and lack of official websites.
- Confirm domain and replace `YOUR-VERCEL-PROJECT` in outreach texts.
- Avoid publishing cold pitch files publicly if you would prefer to keep outreach private: separate the `outreach_pitch.txt` files from your deploy tree before uploading.
- `noindex,nofollow` is used on every concept page to avoid presenting these as official websites. Remove only after owner approval.
