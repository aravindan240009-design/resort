# UAE PropTech 20-client customized concept package

This package contains 20 independently running static demo sites. `customized_clients/` can be deployed as one static project.

**IMPORTANT:** Because the target Drive folder returned a 404, nothing has been uploaded to Drive. Because the lead source was a screening list, no website-null status, Google Photos, reviews or WhatsApp capability has been verified. No URLs have been published or pitches sent.

These are original demo layouts using the *navy-and-gold luxury style direction* described by the GitHub `resort` repository, NOT full copies of its copyrighted third-party website assets. All pictures are original illustrative SVG concept art, not client project photographs.

- `customized_clients/index.html`: portfolio navigation landing page
- `customized_clients/client-XX-.../`: 20 isolated site folders
- `customized_clients/README_DEPLOY.md`: deployment guides
- `outreach_summary.csv`: complete tracking table
- `client_manifest.json`: machine-readable manifest

Review/verify leads and deploy before sending any outreach.
